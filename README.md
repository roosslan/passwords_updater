# passwd_changer

Утилита для смены пароля SAP-пользователя сразу в нескольких системах (SAP JCo Connector)

## Коротко
- Пароль меняется  вызовом `SUSR_USER_CHANGE_PASSWORD_RFC` со старым паролем; `BAPI_USER_CHANGE` и временный пароль не используются.
- Обрабатываются сразу все выбранные системы
- Обращение к SAP выполняется в фоновом потоке, статус показывается для каждой системы
- Новый пароль вводится дважды, поля паролей скрыты
- Список систем хранится в `systems.xml` в виде атрибутов `sid`, `client`, `sysnr`, `host`

## Требования
- JDK 8 или новее, Maven.
- SAP JCo 3.x (`sapjco3.jar` и `sapjco3.dll`) из SAP Support Portal; файлы необходимо поместить в `lib/`. Разрядность библиотеки должна совпадать с разрядностью JVM.

## Сборка и запуск
```
mvn package
run.bat
```
Файл `systems.xml` располагается в текущей директории
